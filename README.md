# АльфСкрин: стратегическая презентация

Локальный React / TypeScript / Vite проект. Дата исследования: 10 ноября 2026. Публичные факты, гипотезы и пробелы разделены в презентации и приложении.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, указанный Vite. Сборка: `npm run build`; предпросмотр: `npm run preview`. После сборки статические файлы находятся в `dist/`; используйте локальный HTTP-сервер.

## Редактирование и управление

Тексты экранов, источники и исходные сценарии — `src/data.ts`; формулы — `src/model.ts`; компоненты — `src/main.tsx`; оформление — `src/style.css`. Параметры калькулятора — сценарные, не финансовые данные компании.

Оглавление, стрелки на экране и клавиатуре, адреса `#1`–`#18`, полноэкранный режим и приложение доступны в интерфейсе. В панели «Анимации» выберите эффект для текущего экрана, длительность и задержку; настройки автоматически сохраняются локально, экспортируются и импортируются JSON-файлом. При системной настройке уменьшения движения анимации отключены.

## Метод и ограничения

Визиты = min(записи, свободные слоты) × явка. Выручка = визиты × чистый чек, маржа = выручка − прямые затраты; поток = маржа − дополнительные ежемесячные расходы; начальные инвестиции учитываются в месяце 0. 12 месяцев без дисконтирования. Безубыточность — постоянные расходы / маржа на визит. Пик потребности — максимальный накопленный дефицит. Упрощённая модель не учитывает налоги, оборотный капитал, переток, сроки запуска, финансирование и базовую экономику; не использовать как инвестиционное заключение.

Полноценные конкурентная корзина, региональная статистика, выборка отзывов, сверка карт, лицензий и внутренних показателей не получены. См. приложение презентации. Прежде чем инвестировать, проверить данные и актуальные требования с медицинским директором и юристом.
